# Documentarian

Documentarian is a research and documentation project exploring how to automatically
turn a **GitHub change** into a **narrated demo video** of the live product.

The end-to-end loop under investigation:

> GitHub change → training script → AI voiceover → login to a demo environment →
> screen capture of the live product → muxed video

## Contents

- [Competitive Analysis](competitive-analysis.md) — a survey of existing tools and
  building blocks across the full pipeline, from GitHub triggers to final video muxing.
